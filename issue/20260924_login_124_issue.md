# Login akun "124" gagal — "Gagal terhubung, coba lagi." (berulang)

Dilaporkan user: akun tes "124" gagal login; issue serupa pernah terjadi sebelumnya lalu muncul lagi.

## Issue

Akun "124" TIDAK bermasalah. Dicek langsung lewat `curl` setelah portal dinyalakan: `POST /api/auth/login` → 200, `/api/me`, `/api/progress`, `/api/leaderboard` → 200, data akun utuh.

Penyebab sebenarnya: **server `portal/` (API login, port 3000) tidak sedang jalan** (`lsof -iTCP:3000` kosong; Postgres 5432 & app 8200 jalan normal). `fetch()` ke portal gagal di level jaringan, dan layar login (`app.ts` `renderAccount` → `submit`) menampilkan fallback generik "Gagal terhubung, coba lagi." — pesan yang sama untuk akun mana pun, jadi terlihat seperti akun 124 yang rusak.

## Root Cause

1. **Portal tidak ikut nyala otomatis.** `app/` (`npm run dev`) dan `portal/` (`npm run dev`) harus dinyalakan terpisah. Tiap restart Mac/tutup terminal/sesi dev selesai, portal mati dan login ikut mati diam-diam.
2. **Pesan error menyamarkan penyebab.** `apiFetch` (`app/src/account.ts`) tidak membedakan "server tidak bisa dihubungi" dari error yang dibalas server — keduanya berakhir jadi pesan generik. Issue sebelumnya (`20260820_1737_issue.md`, server `next start` basi) punya gejala yang SAMA persis, jadi dua penyebab beda terlihat seperti satu bug yang "kambuh".
3. **CORS cuma satu origin.** `portal/middleware.ts` hanya mengizinkan `APP_ORIGIN` persis (`http://127.0.0.1:8200`). App yang dibuka lewat `http://localhost:8200` ditolak browser → gejala identik walau portal hidup.

## Fundamental Solution (sudah dikerjakan)

1. `apiFetch` menangkap kegagalan `fetch()` jadi `ApiRequestError` status 0 dgn pesan jelas: "Server akun belum jalan. Nyalakan dulu: cd portal && npm run dev" (API lokal) / "Server akun tidak bisa dihubungi. Cek internet, lalu coba lagi." (API production). 404 tetap "No HP/email ini belum terdaftar."
2. CORS menerima `localhost` DAN `127.0.0.1` (kembaran host otomatis), `APP_ORIGIN` boleh berisi beberapa origin dipisah koma, header `Vary: Origin`.
3. `app/dev-server.mjs` memperingatkan di terminal kalau portal belum jalan; `npm run dev:all` (`app/scripts/dev-all.mjs`) menyalakan app + portal sekaligus (portal dilewati kalau sudah jalan). Dicatat di `app/README.md`.

Verifikasi: login "124" lewat UI (Playwright, 390px) berhasil di `127.0.0.1:8200` dan `localhost:8200` → diarahkan ke placement test (sesuai desain akun 124). Dengan portal dimatikan, layar login menampilkan "Server akun belum jalan…". Typecheck `app/` & `portal/` lolos.
